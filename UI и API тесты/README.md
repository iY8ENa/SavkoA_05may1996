# Проект автоматизации UI и API-тестов

Данный проект предназначен для автоматизированного тестирования функциональных возможностей сайта altaivita.ru, включая добавление товаров в корзину, удаление товаров и взаимодействие с корзиной посредством API и интерфейсов браузера.

## Структура проекта

Проект организован следующим образом:
UI и API
├── api
│   └── altavita_cart.py
├── tests
│   ├── test_api.py
│   ├── test_basket.py
│   └── test_ff_search_and_cart.py
├── conftest.py
├── README.md
└── run_tests.py
## Основные компоненты

### 1. `api`
Модули для работы с API сервиса AltaVita.

- **altavita_cart.py:** класс для управления корзиной (добавление, удаление товаров).

### 2. `tests`
Директория с тестовыми сценариями:

- **test_api.py:** автотесты API для операций с корзиной.
- **test_basket.py:** тесты для взаимодействия с корзиной через UI (Selenium).
- **test_ff_search_and_cart.py:** тесты поиска и добавления товара в корзину через браузер Firefox.

### 3. `conftest.py`
Конфигурационный модуль с общими настройками для всех тестов:

- Содержит фикстуры для базовой конфигурации URL, инициализации драйверов браузеров и очистки корзины перед каждым тестом.

### 4. `run_tests.py`
Скрипт для удобного запуска всех тестов:

- Позволяет передавать аргументы в команду `pytest` для запуска конкретных тестов или фильтров.

## Настройки и запуск тестов

Для запуска тестов выполните команды в корневой директории проекта:

```bash
python run_tests.py
или непосредственно:


pytest tests/
Требования
Перед использованием убедитесь, что установлены необходимые зависимости Python:

selenium
requests
webdriver-manager
pytest
pytest-allure-adapater (для отчетов Allure)
Установите зависимости через pip:


pip install -r requirements.txt
Отчеты
Отчетность ведется через систему Allure. Для генерации отчета после завершения тестов добавьте аргумент --alluredir reports при запуске:


pytest --alluredir ./reports
Далее, создайте HTML-отчёт командой:


allure serve reports
